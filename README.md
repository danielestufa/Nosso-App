# Nosso App

App do casal: saúde, treinos, desafios, leitura, finanças, painel dos noivos e chat.

## Tecnologia
- React + Vite (site instalável no celular)
- Supabase (login, banco de dados, tempo real, fotos)
- Vercel (hospedagem e envio de notificações)

## Banco de dados
Rode os arquivos da pasta `supabase/` no SQL Editor do Supabase, em ordem.
O `02_notificacao_diaria.sql` só depois de publicar na Vercel.

## Variáveis na Vercel
Veja `.env.example`.
